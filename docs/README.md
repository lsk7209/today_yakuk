# Documentation map

## Current sources

- `/README.md`: local setup, validation, and operational commands
- `/PROJECT_STATE.md`: canonical project state and remaining external boundaries
- `/.goal-harness/`: goal, acceptance criteria, evidence, risks, and review
- `/.github/workflows/`: authoritative automation definitions

## Historical material

Files under `docs/reports/` and older plans or deployment guides are retained as historical snapshots. Their framework versions, database provider, route names, workflow names, and completion claims may be obsolete. Each known conflicting document carries a historical or legacy banner.

Do not copy secrets, execute production data changes, publish content, or operate Vercel based only on a historical document.
