## 공개 정책 교정

- 기존 10개 editorial 원문은 로컬 파일로 보존한다.
- 명시적인 `publication_status=published`가 없으므로 공통 정책 resolver에서 초안으로 판정한다.
- 초안은 블로그 목록, 직접 URL 본문, 정적 파라미터, sitemap, 관련 글에서 노출하지 않는다.
- `noindex`만으로 숨기지 않으며 직접 URL은 404 처리한다.
- 검수 해시·검수자·출처 조건이 충족되지 않으므로 광고는 허용하지 않는다.

## 아직 완료로 올리지 않는 이유

- 5~8개 claim-specific 출처와 section 단위 연결이 아직 완성되지 않았다.
- 본문별 3,500자·90점 품질 게이트 및 약사·의사 전문 검토를 통과하지 않았다.
- 네이버 자동완성 관찰이나 검색량 주장을 사용하지 않았다.
