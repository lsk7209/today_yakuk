https://todaypharm.kr/blog/pharmacy-C1402250

수정 요구:
- /blog/pharmacy-*와 /pharmacy/{id}를 엔터티 ID로 연결해 비교한다.
- 같은 ID라도 기존 글의 고유 정보와 검색 의도를 먼저 확인한다.
- 통합할 유용한 정보는 목적지 상세에 보존한다.
- 301 대상은 실제로 내용을 대체하는 페이지로 정한다.
- 관련 없는 URL을 일괄 홈 리디렉션하지 않는다.
- URL별 유지 / 통합 / 재작성 / 검수 대기 / 폐기 후보를 기록한다.
- 삭제·폐기 실행은 승인된 범위에서만 한다.
- 반복 FAQ, 반복 시간표, 잘못된 조사 “은(는)” 등을 정리한다.
- 비슷한 계절성 건강 글은 주제와 본문을 비교해 통합한다.
- 날짜만 바꿔 최신 글처럼 표시하지 않는다.
- 기존 트래픽·백링크·검색 유입 자료가 접근 가능하면 판정에 반영한다.
- 접근할 수 없는 성과 자료는 추측하지 않는다.

6. 크롤링·색인·사이트맵
================================

현재 확인된 이슈:
- /wiki?type=medicine은 noindex이지만 robots의 광범위 쿼리 차단과 겹친다.
- 페이지네이션과 필터에 서로 다른 canonical·robots 정책이 있다.
- 지역명 별칭 경로를 거쳐 정규 경로로 이동하는 내부링크가 있다.

수정 요구:
- 크롤링 허용과 검색 색인 허용을 분리한다.
- noindex를 읽혀야 하는 공개 URL을 robots로 동시에 막지 않는다.
- 무한 필터·위치 파라미터 URL 생성은 별도의 규칙으로 제한한다.
- 페이지네이션은 콘텐츠와 탐색 목적을 검토해 정책을 정한다.
- 모든 쿼리 URL을 일괄 삭제하거나 1페이지로 canonical 처리하지 않는다.
- sitemap에는 의도한 index 대상의 정상 정규 URL만 포함한다.
- noindex, 리디렉션, 오류, 미완성 URL을 sitemap에서 제외한다.
- lastmod를 실제 의미 있는 변경일과 연결한다.
- 내부링크는 가능한 한 정규 URL을 직접 사용한다.
- 스트리밍 로딩 문구만 보고 본문이 없는 페이지라고 단정하지 않는다.
- 존재하지 않는 URL의 실제 404와 유용한 안내를 유지한다.
- 구조화 데이터는 화면에서 확인 가능한 검증된 사실만 사용한다.
- 가상의 리뷰·평점·전문가·검수 정보를 JSON-LD에 넣지 않는다.

7. 광고 허용 조건과 개인정보
================================

수정 요구:
- 콘텐츠 공개 상태, 검색 색인 여부, 광고 허용 여부를 별도로 관리한다.
- 로딩, 오류, 빈 결과, 404, 준비 중 상태에는 광고를 요청하지 않는다.
- 초기에는 검색·지도·전화 행동 중심 화면의 광고를 보수적으로 제외한다.
- 문의·약관·개인정보 페이지는 광고 제외를 권장한다.
- 검증된 콘텐츠 페이지부터 광고 허용을 검토한다.
- 전화·길찾기·필터·페이지 이동 버튼과 광고를 혼동하게 배치하지 않는다.
- 수동 광고 외에 전역 Auto ads, 앵커, 전면 광고, SPA 전환 후 잔존 광고를 확인한다.
- 실제 계정 설정을 바꿔야 하는 항목은 코드 수정과 구분해 보고한다.
- 기존의 올바른 광고 계정 식별정보를 임의로 교체하지 않는다.
- ads.txt 존재만으로 승인 준비가 끝났다고 보고하지 않는다.

개인정보:
- 위치가 서버·로그·분석 이벤트에 전달되는 실제 경로를 조사한다.
- “위치를 저장하지 않는다”는 문구와 실제 구현을 대조한다.
- 건강 관련 검색어·복용약·정밀 위치를 광고 타기팅용 데이터로 전달하지 않는다.
- 광고·분석 도구의 데이터 처리 내용을 실제 구현에 맞춰 안내한다.
- 해외 방문자 동의 관리 요구는 유입 지역과 광고 방식에 맞게 확인한다.
- 실제 사용하지 않는 정책 문구나 허위 보관·파기 약속을 넣지 않는다.

- GPS 거부·위치 조회 실패 시 지역 검색 대안
- 전화·길찾기 링크의 올바른 대상
- 영업 종료 경계, 공휴일, 자정 넘김, 미확인 시간표
- 통계 분모 0·null, 사람 수와 응답 수 불일치
- 성분 파싱 실패와 첨가물 키워드 오분류
- 본문과 FAQ·JSON-LD의 일치
- 광고 허용 글에서 빈 검색 결과·오류 화면으로 이동하는 흐름
- 모바일 360·390px, 태블릿, 데스크톱의 탐색과 버튼 겹침
- 키보드 탐색, 포커스, 상태의 텍스트 구분
- 대표 페이지의 성능 측정과 확인 가능한 필드 데이터

단순 색상·문구 수정에 불필요한 테스트를 추가하지 않는다.
데이터·시간·파싱·광고 제어처럼 실패 영향이 큰 로직에 검증을 집중한다.
실행하지 못한 테스트와 접근하지 못한 계정 자료는 명시한다.
