## 판정

델타는 자동 발행하지 않는다. 누락 필드와 의료 자료 유형을 사람 검수한 뒤 기존 URL 보완 또는 신규 후보로 분류한다.

## 해석 제한

- 약국 `updated_at`은 동기화 실행 시각이며 전화 확인일이나 원천기관 갱신일이 아니다.
- `public_data_sync_runs`의 최신 실행 기록은 작업 실행 증거일 뿐, 실제 레코드 변화의 증거가 아니다.
- 이 감사는 좌표를 조회하거나 출력하지 않으며 운영 DB를 변경하지 않는다.
- 건기식·의약품 변화는 의료적 정확성이나 전문 검수를 의미하지 않는다.
