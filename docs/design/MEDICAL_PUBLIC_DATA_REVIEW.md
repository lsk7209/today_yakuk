# 의료 문구 및 운영 공개 데이터 점검 — 2026-10-23

## 범위와 경계

임신·수유 약국 이용 글의 편집 오류와 근거 없는 복용 권고를 로컬에서 교정하고, 운영 사이트의 공개 API와 화면을 표본 대조했다. 운영 DB 쓰기·수집·게시·배포·push는 수행하지 않았다. 약사/의사의 전문 검토나 전체 데이터 정확성 인증은 아니다.

## 운영 표본 결과

증거: `.goal-harness/medical-data-20261023/runtime/public-data.json`, 재실행: `node scripts/audit-public-data-rendering.mjs`.
감사 스크립트는 요청 오류·표본 부족·표시 불일치·유해물질 카드 발견 시 exit 1을 반환하고 증거는 보존한다. 현재 운영 오류가 남아 있으므로 감사 전체 판정은 FAIL이다.

- 서울 강남·부산·제주에서 각 2곳, 총 6곳: 이름·주소·전화 일치. 요일/공휴일 48개 표시가 API 등록값과 일치. 누락된 요일은 휴무로 단정하지 않고 정보 없음으로 표시됐다.
- ID: C1110298, C1101940, C1200460, C1202989, C2900184, C2900089.
- 영양제 3개: 이름·제조사 일치. 비타민D/프로바이오틱스 표본은 성분 카드 없음. 이는 성분이 없다는 의미가 아니다.
- **운영 오류 재현**: [패밀리 오메가3 츄어블](https://todaypharm.kr/wiki/product/59fdeb5b-943f-47d0-80b9-fe590f5574e7)에서 카드뮴 1mg, 수은 0.5mg이 영양성분 카드로 표시됨. 이 값은 실제 섭취 함량으로 검증된 값이 아니며, 화면의 기준치 미표시 배지만으로 오류가 해결되지 않는다.
- 로컬 `nutrition-validation`은 해당 오분류 이름을 거부하며 기존 회귀 테스트 9개 PASS. 운영은 별도 앱/배포이므로 이 로컬 결과를 운영 수정 완료로 취급하지 않는다.

## 잔여 작업

운영 영양제 오류는 별도 운영 앱에 검증 로직을 반영하고, 해당 제품 원자료의 기준규격과 실제 함량을 구분해 확인한 다음 배포 후 재검증해야 한다. 이번 작업에서는 실행하지 않았다. 약국의 실제 영업 여부, 수집 원천과 DB의 전체 일치 여부, 영양제 원자료의 정확성은 미확인이다. API의 updated_at은 현장 확인 날짜로 해석하지 않았다.
