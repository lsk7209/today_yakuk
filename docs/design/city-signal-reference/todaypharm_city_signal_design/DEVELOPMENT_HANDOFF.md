# 약국오늘 CITY SIGNAL — 개발 핸드오프 v1.0

## 1. 범위

현재 사용자가 확정한 **A · CITY SIGNAL** 디자인을 적용합니다. 대상은 공개 웹페이지 20종 템플릿입니다. 기존 약국 검색, Turso DB, SEO, 데이터 동기화, 자동 발행, 지도/전화, 애드센스 구성의 정상 기능을 유지하는 것이 전제입니다.

## 2. 시안과 실서비스의 차이

이 패키지는 UI·정보 구조·반응형 스타일의 **정적 프로토타입**이며 데이터/백엔드 작업이 아닙니다. 마크업 예시를 그대로 복붙하여 실제 약국·의약품 운영 데이터로 게시하면 안 됩니다.

- 가상의 예시약국, 정보 미연동 성분·제품은 실제 DB 값으로 교체.
- 검색은 기존 `/api/nearby`, `NearbyClient.tsx` 기능을 재사용.
- 허위 실시간 상태를 표시하지 않으며 등록 시간표와 현장 확인을 구분.
- GPS 거부·오류·검색 결과 없음 상태를 반드시 설계.
- 문의 폼은 목업에서 미전송 상태. 실제 홈페이지의 검증된 연락 방법을 보존.
- `noindex,nofollow`는 **목업이 노출되는 것을 막기 위한 디자인 파일 전용**. 실서비스의 기존 `generateMetadata`/robots/canonical 정책은 보존.

## 3. 개발 구현 규칙

1. **기능 동작 보존:** URL·쿼리·GPS·전화·지도·검색 결과·페이지네이션·성능·접근성 회귀 방지.
2. **디자인 재사용:** 공통 헤더·푸터·검색바·상태배지·데이터 테이블·출처 카드·위키 상세 템플릿을 컴포넌트로 분리.
3. **데이터 정확성:** `src/lib/pharmacy-intelligence.ts`의 근거가 없는 지역 평균 기본값(앞서 확인한 `9.5`시간, 주말 `65%`, 야간 `28%`)과 추정 점수·비교 문구를 검토하고 충분한 데이터가 없는 경우 숨기거나 표본 수와 기준을 명시.
4. **의료 정보 안전:** 의료 면허·전문가 검토를 허위로 표시하지 않음. 실제 신뢰 가능한 출처를 표기. 제품·성분의 누락값을 임의 0·무효 처리하지 않음.
5. **광고 정책:** 운영 중의 광고 제어/표시 정책 유지, 본문보다 광고가 더 두드러지지 않게 구성, 클릭을 유도하는 허위 UI 금지. 애드센스 승인을 특정 수치로 보장하지 않음.
6. **레거시 보존:** GitHub Actions, Turso, 공공데이터 동기화, 환경변수, 도메인, 페이지 경로, canonical, JSON-LD, sitemap 관련 코드의 변경은 꼭 필요할 때만 최소화.
7. **제작 단계:** 먼저 별도 작업 브랜치·PR에서 구현 및 검증. 운영 사이트 배포는 사용자에게 범위·영향을 설명하고 승인받은 뒤 수행.

## 5. 최소 수용 기준

- 대표 뷰포트: 390×844, 768×1024, 1440×900에서 가로 스크롤·버튼 겹침·텍스트 잘림이 없음.
- 접근성: h1 단일, 키보드 포커스, 스킵링크, 모바일 메뉴 및 필터 상태 전달, 주요 버튼 터치 크기 44px 이상 검토.
- E2E: 홈 검색 성공/실패, GPS 허용/거부, 지역 이동, 약국 상세 버튼, 게시글 목차, 위키 카테고리, 광고 제외 라우트, 개인정보/문의 링크.
- SEO: 기존 `robots`, `canonical`, structured data, meta title/description, Sitemap 및 공개 경로 유지.
- 콘텐츠: 없는 리뷰 수·확인되지 않은 통계·가상의 약사 검수 없음. 정책 원문 보존.
- 성능: 실측한 모바일 LCP 2.5초 이하, INP 200ms 이하, CLS 0.1 이하를 목표로 하되 페이지별 측정 결과 보고.
- 기존 자동 발행/동기화·Turso 운영 비용 증가를 불필요하게 유발하지 않음.

## 6. 검증된 내용과 미검증 부분

- 실제로 작성됨: 20종 정적 HTML, 공통 CSS·JS, SVG 2개, 통합 미리보기와 문서.
- 자동으로 수행 가능한 검증: HTML 링크/파일/마크업 구조, CSS 파싱, JS 문법.
- **현 환경의 브라우저 URL 차단 정책으로 자동 브라우저 렌더링과 실제 기능 테스트는 수행하지 못함.** HTML 시안 자체는 보통의 브라우저 환경에서 열도록 설계했으나 최종 PC/모바일 시각 검수 필요.
- GitHub 원본에 코드 커밋·푸시·배포하지 않았음.
