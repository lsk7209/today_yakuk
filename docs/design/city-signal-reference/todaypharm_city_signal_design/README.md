# 약국오늘 — CITY SIGNAL 전체 메뉴 디자인 패키지

- **콘셉트:** A · CITY SIGNAL / 도시 안내 시스템 × 디지털 약국 안내
- **산출물:** 공개 페이지 유형 **20종**의 개별 HTML + PC·태블릿·모바일 뷰포트 전환이 가능한 통합 미리보기
- **상태:** 사용자 검토용 디자인 프로토타입. 운영 사이트·GitHub 코드·Turso DB·AdSense 설정은 변경하지 않았습니다.
- **중요:** 실제 약국 검색, 위치 권한 요청, 전화/길찾기, 문의 발송, 공공데이터·의료 데이터 조회는 구현하거나 연결하지 않은 *목업*입니다. 샘플 데이터는 전부 가상임을 표시했습니다.

## 빠른 사용법

1. ZIP 압축을 **전체 해제**합니다. HTML 파일 하나만 분리해 열면 CSS와 다른 화면을 찾지 못합니다.
2. `preview.html`을 브라우저로 열어 왼쪽에서 메뉴별 페이지를 선택합니다.
3. 상단 **PC / 태블릿 / 모바일**을 눌러 화면 폭을 비교하고, **별도 창**으로 개별 화면을 엽니다.
4. 각각의 디자인 HTML은 `index.html`, `pages/*.html`에 있습니다. 모든 화면은 오프라인 정적 파일이며 상대경로로 연결되어 있습니다.
5. 특정 브라우저가 `file://` iframe을 제한하면 `python -m http.server 8000` 실행 후 `http://localhost:8000/preview.html`을 열어도 됩니다.

## 디자인과 운영 기능의 경계

- 검색창은 사용자가 입력한 문자열을 **가상 검색 화면**으로 전달합니다. 검색 결과는 실제 검색·위치 정보가 아닙니다.
- 반경 3/5/10km, 정렬 및 위키 필터 버튼은 **미리보기용 데이터**에만 반응합니다.
- 위치·전화·지도·수정 요청 버튼은 사용자가 실제 서비스 기능이라고 오해하지 않도록 알림을 보여줍니다.
- 문의 폼은 어떤 정보도 서버에 전송하지 않습니다. 입력된 값은 저장되지 않습니다.
- 개인정보 처리방침과 이용약관은 법적 원문을 임의로 제작하지 않았으며, 디자인 구조만 제공합니다. 운영 사이트의 실제 원문을 유지해야 합니다.
- 가상 제품·약국과 약국 운영시간/의약품 정보는 실제 데이터로 전환할 때 공식 정보로 검증해야 합니다.
- 작업물이 디자인 목업으로 검색엔진에 노출되지 않도록 모든 HTML에 `noindex,nofollow` 메타 태그가 있습니다. **실서비스에 구현할 때 이 목업용 태그를 그대로 복사하지 말고 기존 페이지별 SEO 정책을 유지**하세요.

## 추천 검토 순서

`메인 → 내 주변 → 지역 → 약국 상세 → 가이드 → 블로그 → 위키 → 소개·문의 → 약관/개인정보/404`

**검증 한계:** 자동화된 Chrome 방문은 실행 환경의 브라우저 URL 접근 제한으로 수행할 수 없었습니다. HTML 구조·링크·JS 구문 등은 정적 점검 후 제공하며, 실제 브라우저·모바일 사용성 검증은 개발 반영 전에 별도로 완료해야 합니다.
