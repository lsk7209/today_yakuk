# CITY SIGNAL 디자인 시스템 v1.0

## 브랜드 디자인 컨셉

약국을 찾는 경험을 단순한 카드 리스트가 아니라 **도시의 길 안내 시스템**처럼 설계합니다. 메인 페이지는 대형 타이포그래피로 정체성을 드러내고, 약국 상세는 정보 안내판, 가이드·블로그는 읽기형 편집 지면, 영양제 위키는 데이터 사전 구조를 채택합니다.

| 토큰 | HEX | 용도 |
|---|---|---|
| `--ink` | `#172419` | 차콜, 제목, 경계선, 역상 섹션 |
| `--lime` | `#D9FD4C` | 핵심 CTA, 노선도, 식별 포인트 |
| `--coral` | `#F57851` | 특정 단어 강조, 안내·주의 포인트 |
| `--paper` | `#F4F4EC` | 기본 배경 |
| `--white` | `#FFFEFA` | 입력·본문 종이 면 |
| `--fog` | `#E5EBDF` | 배경 카드, 보조 설명 |
| `--muted` | `#526354` | 부가 정보 |

### 타이포그래피

- 시스템 sans 및 사용 환경의 한글 지원 폰트. 외부 CDN 폰트 요청 없음.
- 대형 히어로: `clamp(47px, 7vw, 104px)`, 굵기 950, 자간 -0.09em.
- 중형 히어로: `clamp(37px, 5.4vw, 77px)`.
- 본문: 14~18px, 넓은 행간. **실서비스 접근성 테스트에서 실제 16px 이상을 우선 검토**.
- 영문 인덱스: 모노스페이스 10~11px, 고대비 사용.

### 레이아웃

- 최대 너비 `1360px`, 거터 `clamp(18px, 3.2vw, 48px)`.
- 2px 차콜 외곽선, 원형보다 각진 구조, 질감보다 정보 밀도와 명확한 계층 구조.
- 데스크톱: 두 컬럼 영웅 영역, 상세 본문 + 보조 패널, 카드 3열.
- 태블릿 ≤ 850px: 내비게이션 모바일 메뉴 전환, 복잡한 두 컬럼 단일화.
- 모바일 ≤ 620px: 단일 컬럼, 1열 카드, 검색 버튼과 입력 분리, 기본 44px 이상 주요 액션.

### 공통 컴포넌트

`site-header`, `signal-bar`, `footer`, `breadcrumbs`, `searchbar`, `btn`, `pill`, `status`, `directory-item`, `fact-strip`, `data-table`, `note`, `article-toc`, `source-block`, `wiki-card`, `feature-poster`, `preview`.

### 시각 언어

- `metro-map.svg`: 실제 위치 데이터가 아닌 브랜드 일러스트. 현장 지도처럼 표현하지 않습니다.
- 거대 `404.`, `CALL FIRST.`, `✳`, `↗` 모티프 및 선명한 고대비 정보판 레이아웃.
- 페이지 유형별 그래픽을 재활용하되 모든 콘텐츠에 같은 히어로를 강제로 반복하지 않습니다.

## 상태 표시 원칙

- `시간표 기준 영업중`과 `현장 확인 영업중`을 별도로 다루고, 후자를 입증할 정보가 없으면 노출하지 않습니다.
- 임의 추천 순위·통계·리뷰·운영 비율·지역 평균을 만들어 표시하지 않습니다.
- 제품 신고 번호·성분 함량은 검증된 원자료가 있을 때만 표시합니다.
- 의료 관련 고지문은 회피를 위한 작은 글씨가 아니라 실제 판단 시점을 고려한 가독성 있는 설명을 배치합니다.

## 광고 디자인 기본

- 광고와 콘텐츠를 명확하게 구분하고 약국 상세 CTA와 오인될 위치에는 두지 않습니다.
- 광고 삽입 여부는 기존 코드 `src/lib/ad-policy.ts`, `src/components/ads/AdSlot.tsx`의 승인·노출 제어를 우선합니다.
- 성능·탐색·콘텐츠 품질을 훼손하는 팝업, 자동 재생, 허위 탐색 CTA는 사용하지 않습니다.
- 애드센스 승인을 보장하는 디자인은 없습니다. 콘텐츠 충실도·운영 정보·정책 준수를 병행 점검해야 합니다.
